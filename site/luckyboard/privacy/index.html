Lucky Board 개인정보처리방침

시행일 2026-11-09

요약

Lucky Board는 회원가입이 없고, 개발자는 이름·이메일·위치 같은 개인정보를 수집하거나 서버로 보내지 않습니다. 저장한 번호와 설정은 기기 안에만 보관됩니다. 광고는 없습니다.

1. 기기에 저장되는 정보

  • 내가 저장한 번호와 저장한 시각
  • 알림 켜기/끄기 설정, 마지막으로 받은 추첨 결과

앱을 지우면 함께 지워집니다.

2. 인터넷 사용

새 추첨 결과를 받기 위해 공개 데이터 주소(smok95.github.io)에서 결과 파일을 내려받습니다. 이때 내 번호나 개인정보는 보내지 않습니다. 해당 서버는 일반 웹 요청과 마찬가지로 접속 기록(IP 주소 등)을 남길 수 있습니다.

3. 알림

알림을 켜면 기기 안에서 매주 토요일 밤 알림을 예약합니다. 외부 푸시 서버를 쓰지 않습니다.

4. 다른 앱과의 연결

LuckyWheel과 번호를 주고받을 때는 기기 안의 앱 링크만 사용하며, 외부로 전송되지 않습니다.
